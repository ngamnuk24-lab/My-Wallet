# MY WALLET – บันทึกรายรับ-รายจ่ายส่วนบุคคล (PWA สำหรับ iPhone)

เว็บแอปพลิเคชันบันทึกรายรับ-รายจ่ายส่วนบุคคล โทนสีเขียวเข้ม-ขาว ออกแบบสำหรับติดตั้งบน iPhone ผ่าน Safari และโฮสต์ฟรีบน **GitHub Pages**

## ไฟล์ภายในแพ็กเกจ
- `index.html` — ตัวแอปพลิเคชันหลัก (ทำงานแบบ Offline-First พร้อมกราฟโดนัทและกราฟรายปีในตัว)
- `manifest.json` — ไฟล์ตั้งค่า PWA (ชื่อแอป, สีธีม, ไอคอนหน้าจอหลัก)
- `sw.js` — Service Worker สำหรับแคชไฟล์ให้เปิดใช้งานได้แม้ไม่มีอินเทอร์เน็ต
- `apple-touch-icon.png` / `icon-192.png` / `icon-512.png` — ไอคอนแอปกระเป๋าเงินสีเขียวเข้มสำหรับหน้าจอโฮม iPhone

## วิธีนำขึ้น GitHub Pages และติดตั้งลง iPhone
1. สร้าง Repository ใหม่บน GitHub (ตั้งเป็น **Public**) เช่นชื่อ `my-wallet`
2. แตกไฟล์ ZIP นี้ แล้วอัปโหลดไฟล์ทั้งหมด (`index.html`, `manifest.json`, `sw.js`, ไฟล์ไอคอน `.png` และ `README.md`) เข้าไปใน Repository
3. ไปที่แท็บ **Settings** > **Pages** > ในหัวข้อ **Build and deployment** เลือก Branch เป็น `main` (โฟลเดอร์ `/ (root)`) แล้วกด **Save**
4. รอประมาณ 1–2 นาที จะได้ลิงก์เว็บไซต์ เช่น `https://<ชื่อผู้ใช้>.github.io/my-wallet/`
5. เปิดลิงก์ดังกล่าวด้วยแอป **Safari** บน iPhone
6. แตะปุ่ม **แชร์ (Share)** ด้านล่างหน้าจอ > เลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)** > แตะ **เพิ่ม (Add)**
